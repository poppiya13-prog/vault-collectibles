# THE VAULT

ต้นแบบเว็บราคาอ้างอิงและตลาดซื้อขายฟิกเกอร์สะสมมือสองในไทย

## เปิดดู

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `styles.css` | ธีมตู้โชว์ — แก้สีได้ที่ตัวแปรใน `:root` |
| `market-data.js` | ราคาอ้างอิงจากแหล่งภายนอก + `MarketMath` สำหรับคำนวณ |
| `app.js` | ตรรกะทั้งหมด — `MODELS`, `SEED_LISTINGS`, `Store` |

## หลักการของข้อมูลราคา

ทุกรายการใน `market-data.js` มีสองฟิลด์ที่ห้ามตัดทิ้ง

- `status` — `asking` ราคาตั้งขาย · `sold_displayed` ประกาศระบุขายแล้ว · `ended` ปิดประกาศโดยไม่ยืนยันว่าขายได้
- `evidence` — `page` เปิดหน้าจริง · `index` เห็นจากผลค้นหา

ช่วงราคาที่แสดงคิดจาก `asking` เท่านั้น ราคาตั้งขายไม่ใช่ราคาที่ซื้อขายกันจริง
และยังไม่รวมค่าส่งมาไทย ภาษี หรือค่าธรรมเนียมนำเข้า

## ข้อควรระวังเรื่องสิทธิ์

- การขายฟิกเกอร์ **ของแท้** มือสองต่อ ไม่ผิดกฎหมายลิขสิทธิ์หรือเครื่องหมายการค้า ตามหลักการสิ้นสิทธิ์
- การระบุชื่อรุ่นและชื่อตัวละครในประกาศ เป็นการบอกว่าสินค้าคืออะไรตามจริง ทำได้
- **ห้าม** ใช้ชื่อหรือโลโก้ของเจ้าของลิขสิทธิ์เป็นชื่อแบรนด์ โดเมน หรือหัวข้อของเว็บ
- **ห้าม** โฮสต์รูปโปรโมตของผู้ผลิต — รูปทุกใบต้องมาจากผู้ขายถ่ายเอง
- ต้องมีช่องทางรับแจ้งและนำประกาศออกได้เร็ว ซึ่งเป็นเงื่อนไขของการได้รับยกเว้นความรับผิด
  ตาม พ.ร.บ.ลิขสิทธิ์ (ฉบับที่ 5) พ.ศ. 2565

ไม่ใช่คำแนะนำทางกฎหมาย — ก่อนเปิดเชิงพาณิชย์ควรให้ที่ปรึกษาด้านทรัพย์สินทางปัญญาตรวจอีกครั้ง

## ขั้นต่อไป

1. เก็บราคาจริงเพิ่มให้ครบ 50 รุ่น ในหมวดเดียว
2. ย้าย `MODELS` และ `MARKET_DATA` ไป Supabase — `Store` ใน `app.js` คือจุดเดียวที่ต้องแก้
3. เพิ่ม LINE Login และที่เก็บรูปของผู้ขาย
4. ทำเป็น PWA แล้วค่อยพิจารณาแอป

## สถานะ

ต้นแบบ ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องที่เปิดเท่านั้น ไม่มีเซิร์ฟเวอร์ ไม่มีการตัดเงิน
